# KI득KI득 🎲

> 같은 기수, 키득키득 — 새 기수의 어색함을 깨는 아이스브레이킹 미니게임룸

KI득KI득은 KDA(키움 산하 교육기관) 새 기수가 처음 만났을 때 서로 어색함 없이 친해질 수 있도록 만든 **LAN 미니게임 모음**입니다.
설치 없이 exe 하나로 실행하고, 같은 와이파이에 있는 동기들과 **체스 · 야추 다이스 · 오목**을 함께 즐길 수 있어요.
게임만 하는 것이 아니라 채팅, 스티커, 도발 멘트, 티배깅 같은 장난 요소로 자연스럽게 말을 걸고 웃을 수 있게 하는 것이 목표입니다.

- 만든 사람: **KDA 5기 송재혁**
- 개발 과정과 고민: [DEVLOG.md](DEVLOG.md)

---

## 기획 의도

| 문제 | KI득KI득의 해결 |
| --- | --- |
| 처음 만난 동기에게 먼저 말 걸기가 어렵다 | 게임 한 판이 대화의 시작이 되도록, 결과 화면에 도발 멘트 · 티배깅 · 스티커를 넣음 |
| 다 같이 하려면 설치나 계정이 번거롭다 | exe 하나 더블클릭, 계정 없이 닉네임과 프로필만 정하면 끝 |
| 인원이 많으면 구경만 하는 사람이 생긴다 | 관전 모드 + 채팅으로 구경하는 사람도 함께 떠들 수 있음 |
| 누가 잘하는지 궁금하다 | 이 PC에서 한 판들의 누적 랭킹 |

## 주요 기능

- **게임 3종**
  - 체스: 컴퓨터 대전 · 한 PC 2인 · 네트워크, 시간 모드(무제한 / 10분 / 3분+2초), 판 돌리기, 방장 사기 모드(장난용)
  - 야추 다이스: 최대 6명, 컵을 흔들어 던지는 물리 효과, 점수표 설명 말풍선
  - 오목: 쌍삼 금지 / 자유룰, 컴퓨터 대전
- **같은 와이파이 멀티플레이**: 방 만들기 / 참가하기 / 관전하기
  - **열린 방 자동 검색**: IP를 몰라도 같은 와이파이에 열린 방이 목록으로 보여요 (눌러서 바로 참가 / 관전)
  - **연결이 끊겨도 이어서**: 와이파이가 잠깐 끊기면 30초 동안 자동으로 다시 접속해 판을 이어가요
  - 자주 가는 방(IP) 저장
- **프로필**: 귀여운 동물 캐릭터 8종 또는 내 사진 + **한 줄 소개**(MBTI, 관심사...) — 참가자 목록에 함께 보여요
- **채팅과 스티커**: 직접 그린 스티커 8종, 상대 쪽 구석에 작게 팝업
- **결과 화면**: 도발 멘트 버튼, 이긴 사람만 쓸 수 있는 화려한 티배깅, **진 사람 질문 카드**("최애 점심 메뉴는?")
- **랭킹**: 이 PC 누적 기록 + **우리 반 랭킹**(같은 와이파이에서 켜 둔 친구들의 기록을 모아서)
- **효과음**: 기물 · 돌 놓는 소리, 주사위 굴러가는 소리, 승리/패배, 티배깅 '쿵' (첫 화면에서 끄기 가능)
- **컴퓨터 난이도**: 쉬움 / 보통 / 어려움, **규칙 보기** 화면
- **무르기 제한**: 컴퓨터 대전은 무제한, 사람끼리는 한 판에 2번 (네트워크는 상대 PC와 맞춰서)
- **참가자 현황**: 플레이어와 관전자 목록
- **화면 크기 적응**: 작은 노트북부터 큰 모니터까지 글자 · 버튼 · 카드가 비율에 맞게
- **새 버전 알림**: 저장소의 `VERSION`보다 오래된 버전이면 첫 화면에 '새 버전 받기' 버튼

## 다운로드와 실행

`release` 폴더에 있습니다.

| 파일 | 설명 |
| --- | --- |
| `release/windows/KI득KI득.exe` | **추천** — 게임 3종이 모두 들어 있는 게임룸 |
| `release/windows/Chess.exe`, `Yacht.exe`, `Omok.exe` | 게임 하나만 따로 실행 |
| `release/mac/KI득KI득_mac.zip` | 맥용 (압축을 풀고 `KI득KI득 실행.command` 더블클릭) |
| `release/mac/chess_mac.zip` 등 | 맥용 게임 하나씩 |

- **Windows**: exe를 더블클릭하면 됩니다. 처음 실행할 때 SmartScreen 경고가 뜨면 `추가 정보 → 실행`을 누르세요. 방화벽 허용 창이 뜨면 **개인 네트워크 허용**을 눌러야 다른 PC가 접속할 수 있어요.
- **Mac**: Python 3이 필요합니다(없으면 설치 페이지가 열려요). 처음에 '확인되지 않은 개발자' 경고가 뜨면 우클릭 → 열기.

### 같이 하는 법

1. 모두 같은 와이파이(또는 핫스팟)에 연결합니다.
2. 한 사람이 게임을 고르고 **네트워크 → 방 만들기**를 누르면 화면에 내 IP가 보여요.
3. 나머지는 **참가하기**(또는 **관전하기**)를 고르면 '지금 열린 방' 목록이 보여요. 방을 누르고 참가하면 끝!
   (목록에 안 보이면 방장 IP를 직접 입력하세요. 한 번 접속한 방은 '자주 가는 방'에 저장돼요.)

여러 팀이 동시에 해도 괜찮아요. 방장 PC마다 별개의 방이라 체스 2팀, 야추 3팀, 오목 5팀이 함께 해도 섞이지 않아요.
방 목록과 우리 반 랭킹은 UDP 포트 50010, 게임은 50007(체스) · 50008(야추) · 50009(오목)을 써요.

### 소스로 실행

```bash
pip install pillow
python hub/game_room.py
```

Python 3.10 이상, tkinter가 포함된 Python이 필요합니다. 각 게임만 따로 실행하려면 `python chess/chess_game.py` 처럼 실행하세요.

## 폴더 구조

```
hub/        게임룸(첫 화면) + 공통 모듈
  game_room.py   첫 화면, 메뉴, 랭킹, 정보, 자주 가는 방
  ui_kit.py      그라데이션 배경, 둥근 카드/버튼, 참가자 카드
  avatars.py     동물 캐릭터 · 사진 프로필
  chat.py        채팅창, 스티커
  party.py       결과 카드, 도발 멘트, 질문 카드, 티배깅 효과
  lan.py         같은 와이파이 방 목록 / 우리 반 랭킹 (UDP 방송)
  sound.py       효과음 (코드로 만든 소리)
chess/      체스 (규칙 엔진, 컴퓨터, 네트워크, 화면)
yacht/      야추 다이스
omok/       오목
fonts/      주아체 (SIL OFL)
release/    빌드된 exe와 맥용 zip
tests/      자동 테스트 (python -m unittest discover -s tests)
VERSION     현재 버전 (앱이 새 버전 알림에 사용)
```

## exe 직접 만들기

```bash
pip install pillow pyinstaller
pyinstaller --onefile --windowed --name KI득KI득 ^
  --paths chess --paths yacht --paths omok --paths hub ^
  --hidden-import avatars --hidden-import party --hidden-import chat --hidden-import ui_kit ^
  --hidden-import lan --hidden-import sound ^
  --add-data "fonts;fonts" hub/game_room.py
python hub/make_mac_zip.py
```

깨끗한 가상환경에서 빌드해야 exe가 약 21MB로 작게 나와요.

## 테스트

```bash
python -m unittest discover -s tests -v
```

체스 수 생성(perft), 체크메이트, 오목 장목 · 쌍삼, 야추 점수, 질문 카드 동기화, 방 목록 메시지, 효과음 생성을 확인해요.
